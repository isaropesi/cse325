## Project Title
**BudgetWise — Personal Finance & Budget Tracker**

---

## Project Overview
BudgetWise is a web application that helps users track their income and expenses, set monthly budget limits by category, and visualize their spending habits. Many students and young professionals lack a simple tool to stay on top of their finances — BudgetWise fills that gap.

Target users are students and young professionals who want to build better spending habits without the complexity of traditional financial software. The app is valuable because it combines secure private accounts, intuitive CRUD-based transaction logging, and visual budget summaries in one clean, responsive interface.

---

## Project Scope

**IN:**
- User registration and login (authentication)
- Add, view, edit, and delete transactions (CRUD)
- Spending categories with monthly budget limits
- Dashboard with income/expense totals and category progress bars
- Responsive design for mobile and desktop
- Cloud deployment

**OUT:**
- Bank account or API integrations
- Investment tracking
- Multi-currency support
- Native mobile app
- Email notifications

---

## App Features
1. Users can create a secure account and log in
2. Users can add, edit, and delete income and expense transactions
3. Users can categorize transactions (e.g., Food, Rent, Transport)
4. Users can set monthly budget limits per category
5. Users can view a dashboard with spending summaries and progress bars
6. Users can filter transaction history by month or category
7. Users can access the app on any device (responsive design)

---

## Technical Considerations
- **Framework:** .NET Blazor Web App (C#)
- **Authentication:** ASP.NET Core Identity
- **Database:** Entity Framework Core + SQLite (dev) / PostgreSQL (production)
- **External Services:** None
- **Device Support:** Responsive — desktop, tablet, and mobile
- **Security:** Identity auth, HTTPS, user-scoped data
- **Deployment:** Azure App Service
